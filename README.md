## 💰 AI Revenue Recovery Engine

**AI + LLM + Razorpay + Python**

An event-driven AI system designed to detect failed payments, diagnose failure causes, select safe recovery actions and compare AI decisions against a deterministic baseline.

### ✨ Highlights

- 💳 Failed payment detection
- 🧠 LLM-based failure diagnosis
- 🛡️ Confidence-based safety gating
- 🔁 Intelligent payment recovery
- 💾 Idempotent SQLite state management
- 💰 Net Recovered Value evaluation
- 📊 AI vs deterministic baseline comparison
- 🔌 Razorpay API integration
- 🧪 Automated testing

The system uses structured diagnosis outputs and a confidence threshold to prevent low-confidence AI decisions from triggering recovery actions. 

**Tech:** `Python` `Pydantic` `LLM` `Razorpay API` `SQLite` `Pytest`
